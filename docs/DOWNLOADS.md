# Choose your store package

Use **Releases → Assets** for the installable ZIPs. The download links below point to the current official website packages.
Those website packages can have different ZIP checksums because this GitHub
publication adds documents and licenses. See the release manifest for the
checksums of the GitHub assets. GitHub release links can be configured using
the optional tool described in GITHUB_SETUP.md.

Every branch has a separate archive. The PHP range must also be permitted by
your exact store release; do not infer that every listed core supports every
PHP version in a broad branch range.

The 8 newer packages (Shopware 6.6/6.7, Drupal Commerce, EC-CUBE, Bagisto,
Sylius, osCommerce and thirty bees) are initial integration builds. Verify them
in a complete staging store before enabling live traffic. No native-store
certification or exhaustive real-payment acceptance is claimed here.
