# Buyer languages

Payment popup UI build78 is unchanged from the current Multilanguages assets. English, Chinese, Spanish, Brazilian Portuguese, French, German, Dutch, Persian, Russian and Arabic, including RTL. Explicit lang takes priority, then saved/browser preferences, then English. The language selector only changes presentation; amount, address, identity, mode and server verification do not change. Instructions and staging controls remain English. HPP receives the selected language on the same order.
